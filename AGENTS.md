## Technical baseline (must always hold)
- compileSdk = latest stable Android platform (may be higher than targetSdk); targetSdk 36 (Google Play requirement); minSdk 26. Google Play requires API 36 for new apps and updates.
- Edge-to-edge is mandatory on API 35+: every screen must handle WindowInsets (status bar, navigation bar, display cutout). Nothing may sit under system bars.
- Predictive back: use OnBackPressedDispatcher / Compose BackHandler only. No onBackPressed() overrides, no KEYCODE_BACK handling.
- Saving images: MediaStore API only. No WRITE_EXTERNAL_STORAGE, no READ_EXTERNAL_STORAGE, no MANAGE_EXTERNAL_STORAGE.
- Sharing: FileProvider + Android share sheet.
- Room: exportSchema = true, schemas folder committed, every schema change ships with a Migration or AutoMigration. Never use fallbackToDestructiveMigration in release.
- No hardcoded secrets or ad unit IDs in Kotlin code — they come from BuildConfig fields per build type.
- Request the minimum permissions possible. List every permission in the manifest in each walkthrough.

## Content rules (legal safety)
- Quotes: only (a) original quotes written for this app, attributed to "Aura Quotes", or (b) quotes by authors who died 70+ years ago with well-documented attribution. No song lyrics, no modern book or film quotes, no living authors. Never guess an attribution — if unsure, mark it as original or drop it.
- Images: only images that exist in this repo under app/src/main/assets or res, with credits recorded in credits.json. Never hotlink random URLs.

## Ad policy rules (AdMob / Play)
- Debug builds ALWAYS use Google's official test ad unit IDs. Release builds use real IDs from BuildConfig. This switch must be automatic per build type.
- No ad on cold start or splash. No ad placed adjacent to tappable buttons. No interstitial on screen switches or during content loading.
- Every ad container has a fixed, reserved size so layouts never jump or overlap.
- Ads load only after the UMP consent flow completes and MobileAds is initialised.
